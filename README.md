# crack-me-if-you-can

[![CI](https://github.com/pedromiguel97/crack-me-if-you-can/actions/workflows/ci.yml/badge.svg)](https://github.com/pedromiguel97/crack-me-if-you-can/actions/workflows/ci.yml)

A password strength meter based on passwordmeter.com rules, versus an AI attacker agent that tries to guess passwords using a fictional persona dossier.

**Thesis:** a high rule-based score doesn't mean a strong password.
